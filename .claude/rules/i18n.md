# i18n rules (auto-loaded when touching files that contain user-facing text)

## Hard rules

- **Never hardcode any string.** No exceptions.
- Every key must exist in **both th and en** — missing either side = not done
- th is the default locale

## Things that usually get missed (must be translated too)

input placeholders / aria-label, alt, title / zod validation messages /
toasts and notifications / empty states, loading text / 404, 500, unauthorized pages /
buttons in confirm dialogs / table headers / status names / email templates / page title and meta

## Key structure

This project uses **one file per locale** (`messages/en.json`, `messages/th.json`, ~1250 lines each), not split
by namespace — that's the existing convention, keep it (don't fragment into multiple files as a side task).
Keys are **2 levels**: `<page-or-feature>.<element>`, e.g.:

```
login.emailLabel
vehicleForm.addTitle
overdue.fetchError
```

Add new keys under the existing top-level namespace for that page/feature (see the top-level keys already
in `messages/en.json`: `login`, `sidebar`, `header`, `dashboard`, `vehicles`, `fleetMap`, `customers`, `contracts`,
`invoices`, `alerts`, `common`, ...). Only introduce a new top-level namespace for a genuinely new page/feature.

## Common mistakes

| Topic | Do |
|---|---|
| Date/time | store UTC, convert on display, use the i18n formatter — **never concatenate strings yourself** (see `lib/date.ts`, `lib/format-relative-time.ts`, `lib/parse-flexible-date.ts`) |
| Buddhist / Gregorian year | **not implemented yet** — this project currently shows Gregorian years only in both th and en. If a page needs Buddhist year (พ.ศ.), stop and ask first; don't add an ad-hoc `+543` in one file |
| Numbers / money | `Intl.NumberFormat` per locale |
| Plurals | the library's plural system, not hand-written `if` |
| Sorting Thai text | `Intl.Collator` |
| Backend errors | backend sends `error.code` → **frontend maps to an i18n key**; never show the raw message |
| Thai line height | upper/lower vowels need more line-height (~1.6–1.75 for body) |

## Before finishing

- [ ] grep for raw Thai/English text in tsx files and find none
- [ ] keys complete in both th and en
- [ ] opened the page in both languages and the layout holds
